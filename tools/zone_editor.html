What to draw (in this order)

  1. road: the whole carriageway, junction included
  2. crosswalk: each zebra crossing
  3. island: median strip and refuge islands
  4. stop_line: each approach's stop line
  5. signal: each visible light head, note which approach
  6. lane_dir: one arrow per lane group
  7. solid_line: solid markings
  8. intersection: the junction box
  9. bus_stop / parking
  10. approach arms (name them) + notes on banned turns

Keys

Click = add point · Enter/double-click = finish · Backspace = remove last point · Esc = cancel · wheel = zoom · right-drag or Space+drag = pan · edit mode: drag a vertex, click a shape to select, Del deletes.
